# 「药知道」安卓端联调说明（给安卓开发同学）

后端已按 `MedKnow.md` 接口文档完整实现（30 个接口），本文件是**联调时的最终约定**，与 API 文档不一致处以本文件为准。

## 1. 后端地址

| 调试方式 | 地址 | 说明 |
|---|---|---|
| Android 模拟器 | `http://10.0.2.2:8090/api/v1` | 10.0.2.2 = 模拟器访问宿主机 localhost 的固定别名 |
| 真机（同一 Wi-Fi） | `http://192.168.2.10:8090/api/v1` | 电脑局域网 IP，`ipconfig` 可查 |

- 所有接口路径前缀 `/api/v1`，共 30 个，见 `MedKnow.md`
- 后端日志里打印请求 SQL，调试时可以对照

## 2. 登录流程（开发模式，不需要接短信）

1. `POST /api/v1/auth/send-code` body `{"phone":"13800138000"}`
   → 响应 `data.devCode` **直接返回验证码**（开发模式；上线后改为真实短信，此字段移除，App 按可空处理）
2. `POST /api/v1/auth/login` body `{"phone":"...","code":"<验证码>"}`
   → 响应 `data.token`（JWT，有效期 7 天）
3. 之后所有请求带请求头：`Authorization: Bearer <token>`
4. **新用户首次登录自动注册**，账户状态 PENDING（信息未完善），此时不能创建用药计划（返回 40301），需先 `PUT /api/v1/user/profile` 补全昵称/年龄/性别/职业 → 状态变 NORMAL

**测试账号**：`13800138000`（张大爷，已完善资料，可直接创建计划）

## 3. 响应约定（最重要）

- 统一响应体：`{"code": 0, "message": "...", "data": {...}}`
- **成功判断：`code == 0`**（不要判断 HTTP 200/201，不要判断 message）
- HTTP 状态码与业务码的关系：

| HTTP | code 范围 | 含义 |
|---|---|---|
| 200/201 | 0 | 成功 |
| 400 | 1001~1004、4000~40010 | 参数/验证码错误 |
| 401 | 4010 / 4011 | Token 过期 / 未登录 |
| 403 | 40300~40302 | 无权限（40301 = 信息未完善） |
| 404 | 40401~40404、3001 | 资源不存在 |
| 409 | 40901~40905 | 状态冲突（已打卡/已在药箱等） |
| 500 | 50000 | 服务器错误 |

- **日期时间格式统一为 `yyyy-MM-dd HH:mm:ss`**（如 `2026-08-06 07:00:00`）；日期为 `yyyy-MM-dd`
- `/api/v1/health` 是唯一例外：独立格式 `{"status":"ok","timestamp":"..."}`，不走统一包装

## 4. 认证分级（哪些接口要 token）

| 级别 | 接口 | 说明 |
|---|---|---|
| 必须登录 | `/user/**`、`/medication-plans/**`、`/checkins/**`、`/drugs/{id}/collect`、`/articles/{id}/collect`、`/articles/{id}/like` | 无 token 返回 4011 |
| 可选登录 | `/articles/**`（除互动接口） | 未登录可浏览，登录后 isLiked/isCollected 才有真实值、推荐更精准 |
| 公开 | `/auth/**`、`/health`、`/feedback`、`/drugs/search`、`/drugs/{id}`、`/hospitals/**` | 无需 token |

## 5. Android 端注意（踩坑预警）

1. **明文 HTTP**：Android 9+ 默认禁止明文 HTTP，必须在 `AndroidManifest.xml` 配置 `networkSecurityConfig` 或 `usesCleartextTraffic="true"`（开发期），否则请求直接被拦
2. **10.0.2.2 只适用于模拟器**；真机必须用电脑局域网 IP 且同一 Wi-Fi
3. **头像上传**：`POST /user/avatar` multipart 字段名 `file`，限 jpg/jpeg/png ≤2MB；返回的 `avatarUrl` 是按请求 Host 动态拼的（模拟器访问就是 10.0.2.2 地址，直接可显示）
4. **提醒状态机**：`PENDING→TRIGGERED→TAKEN/EXPIRED`，后端接口会在查询时自动翻转状态；本地闹钟只负责"到点响铃+跳转页面"，打卡调 `POST /checkins`
5. **依从率统计**：`GET /checkins/stats?period=WEEK|MONTH`，WEEK=近7天、MONTH=近30天（滚动窗口，非自然周，与 PRD 略有差异，以本文件为准）
6. **点赞/收藏是切换式**：同一接口点两次 = 赞→取消赞，响应里返回最新状态（isLiked/isCollected），前端直接用它更新界面

## 6. 快速自测（不用等后端同学）

```bash
# 发验证码（响应直接给 devCode）
curl -X POST http://localhost:8090/api/v1/auth/send-code \
  -H "Content-Type: application/json" -d '{"phone":"13800138000"}'

# 登录拿 token
curl -X POST http://localhost:8090/api/v1/auth/login \
  -H "Content-Type: application/json" -d '{"phone":"13800138000","code":"<devCode>"}'

# 带 token 查个人资料（手机号脱敏）
curl http://localhost:8090/api/v1/user/profile \
  -H "Authorization: Bearer <token>"
```

## 7. 接口清单速查（30 个，详见 MedKnow.md）

- **用户**：send-code / login / profile(GET,PUT) / settings / avatar
- **用药计划**：创建 / 列表(状态筛选+分页) / 详情 / 更新 / 激活 / 暂停 / 恢复
- **打卡**：打卡 / 今日待打卡 / 依从率统计(WEEK/MONTH)
- **药品**：搜索 / 详情 / 收藏药箱
- **医院**：推荐(经纬度+科室筛选) / 详情 / 搜索
- **文章**：推荐 / 分类列表 / 详情 / 收藏切换 / 点赞切换 / 分享
- **通用**：health / feedback
